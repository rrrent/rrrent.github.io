プライバシーポリシー

最終更新: 2026年10月17日

取得する情報

すきま分析（以下「本ツール」）は、運営者本人が許可した YouTube チャンネルについて、YouTube Analytics API から再生数・視聴時間・視聴維持率などの集計データを読み取ります。読み取り専用の権限（yt-analytics.readonly）だけを使います。

利用目的

取得したデータは、運営者が自分のチャンネルの動画づくりを改善するための集計にだけ使います。

第三者への提供

取得したデータを販売したり、第三者に提供したりしません。本ツールは運営者本人だけが使い、ほかの利用者の情報は取得しません。

保存と削除

集計結果は運営者が管理する非公開の保存先にだけ保存します。アクセスの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Google API の利用

本ツールによる Google API から受け取った情報の使用は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

Privacy Policy (English)

Sukima Analytics reads aggregated analytics (views, watch time, audience retention) from the YouTube Analytics API for the channel its owner has authorized, using only the read-only scope. The data is used solely to help the owner improve their own videos, is stored only in the owner's private storage, and is never sold or shared. The tool is used only by its owner and collects no data about other users. Access can be revoked at any time in your Google Account under third-party apps and services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
