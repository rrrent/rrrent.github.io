すきま分析

YouTube チャンネルの運営者が、自分のチャンネルの再生データ（再生数・視聴時間など）を読み取って集計するための、個人用のツールです。一般の利用者向けのサービスではありません。

利用するのは YouTube Analytics API の読み取り専用の権限（yt-analytics.readonly）だけで、動画の投稿・編集・削除は行いません。

プライバシーポリシー

Sukima Analytics is a personal tool that lets a YouTube channel owner read and summarize analytics for their own channel. It uses only the read-only YouTube Analytics scope and never uploads, edits or deletes videos. Privacy policy
